05The file format

It's just a text file.

A .md (Markdown) file is plain text with a few light marks for structure. No software, no code — it opens in Notes, Word, anything.

md file
# Brand Voice
 
Warm, precise, a little *dry*.
→
Anyone reads it
Brand Voice

Warm, precise, a little dry.

# becomes a heading. *word* becomes italic. That's the whole trick — and exactly the format AI reads best.
